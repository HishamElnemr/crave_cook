## 📱 About

CraveCook is a simple and clean mobile app for discovering and browsing food recipes. Users can explore recipes by category and view full recipe details — all fetched from an external API.

---

## ✨ Features

- 🍽️ **Browse Recipes** — Explore a wide variety of food recipes
- 🗂️ **Category Browsing** — Filter recipes by food category
- 📖 **Recipe Details** — View full recipe information
- ⚡ **Fast & Smooth** — Clean UI with smooth navigation

## 🚀 Getting Started

### Prerequisites
- Flutter SDK `>=3.0.0`
- Dart SDK `>=3.0.0`

### Installation

```bash
# Clone the repo
git clone https://github.com/HishamElnemr/crave_cook.git

# Navigate to project
cd crave_cook

# Install dependencies
flutter pub get

# Run the app
flutter run
```
